# Instituto e Clínica Lucimar Gramoza — Landing page

Site responsivo em HTML, CSS e JavaScript, preparado para hospedagem estática (GitHub Pages, Netlify ou hospedagem própria).

## Arquivos
- `index.html` — página completa, estilos e interações.
- `assets/estetica-corporal.jpg` — imagem corporal fornecida.
- `assets/limpeza-facial.jpg` — imagem facial fornecida.
- `assets/logo-referencia.png` — logo fornecido como referência visual.

## Visualizar localmente
Abra `index.html` no navegador. Não precisa instalar dependências.

## Publicar no GitHub Pages
1. Crie um repositório no GitHub.
2. Envie `index.html`, a pasta `assets/` e este README.
3. No repositório, acesse **Settings → Pages**.
4. Em **Build and deployment**, selecione **Deploy from a branch**.
5. Escolha a branch `main` e a pasta `/ (root)`, salve e aguarde a publicação.

## Antes de divulgar
- Confirme o número do WhatsApp e os dados de contato.
- Confira se os procedimentos apresentados correspondem aos serviços atualmente oferecidos.
- Acrescente depoimentos e fotos de resultados somente com autorização e evidências reais.
- Revise as informações profissionais/regulatórias e adicione uma política de privacidade adequada caso passe a coletar ou armazenar dados.
- O formulário abre o WhatsApp com os dados preenchidos; não salva os dados em um servidor.
